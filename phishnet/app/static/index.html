      How a URL becomes a verdict

      1. Normaliselower-case, drop https:// and www.
      2. Embedeach character → 64-d vector, max 128 chars
      3. Convolvekernels 3 · 5 · 7 find n-grams like paypa1, -login, .top
      4. BiLSTMreads the patterns in order, both directions
      5. Attendweighs positions, pools to one vector
      6. Classifydense layer → sigmoid → P(phishing)
